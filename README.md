# 兒童視覺化計時器 Kids Timer

**繁體中文** | [English](./README.en.md)

專為兒童設計的視覺化倒數計時器（PWA），透過隨著時間流逝而縮小的色塊扇形，幫助孩子直覺理解時間概念。支援 iPhone (Safari) 與 Android (Chrome) 加入主畫面安裝為離線獨立 App。

🔗 **線上使用網址**：https://tomroy.github.io/kids-timer/

---

## ✨ 主要功能

- **三種轉盤模式**
  - 🔵 **藍色快鐘**：最高 15 分鐘（每 15 秒一細格），適合刷牙、收玩具、出門準備等短時間任務。
  - 🔴 **紅色慢鐘**：最高 60 分鐘，適合寫作業、看書閱讀、吃飯時間。
  - 🎨 **自訂轉盤**：可於設定中自訂最大分鐘數（1 ~ 180 分鐘）與 6 種主題色塊（天空藍、活力紅、森林綠、陽光橘、夢幻紫、蜜桃粉）。
- **直覺觸控拖曳與雙層視覺區分**
  - 直接點選或拖曳轉盤握把即可設定時間，並提供 `-1 分`、`+1 分`、`+5 分` 快速微調。
  - 倒數進行中會以淺色底色保留「原本設定的總時間」，讓使用者一眼看出已流逝與剩餘時間的比例。
- **任務標籤與長按排序**
  - 內建日常任務（「🚀 出門」預設 15 分鐘、「🧸 收玩具時間」、「🪥 刷牙洗臉」、「📚 看書閱讀」、「✏️ 寫作業」、「🍽️ 吃飯時間」、「🎮 遊戲時間」、「🛁 洗澡時間」、「🛏️ 準備睡覺」）。
  - **長按任一任務標籤**即可左右拖曳調整排列順序，並自動記住排序。
  - 支援「➕ 自訂任務」，可自由挑選圖示、名稱與預設分鐘數。
- **雙語系介面（繁體中文 / English）**
  - 自動偵測瀏覽器語系（未支援語系預設顯示英文），亦可於設定中手動切換語言。
- **提醒音效與慶祝動畫**
  - 內建 4 種 Web Audio 合成音效（歡樂木琴、清脆鐘聲、溫柔豎琴、經典鬧鈴），完全離線可用。
  - 時間到時會播放慶祝彩帶動畫，並提供「完成任務」或「+2 分鐘」按鈕。
- **家長貼心設計**
  - 🔒 **兒童防誤觸鎖**：點一下鎖定轉盤與按鈕，長按 1.2 秒才可解鎖。
  - 🔊 **秒針滴答聲開關**與倒數最後 1 分鐘閃爍提醒。
  - 📱 **螢幕恆亮 (Wake Lock)**：計時進行中自動防止手機螢幕休眠。

---

## 📲 手機安裝方式 (PWA)

- **iPhone (Safari)**：開啟網址後，點選下方「分享」按鈕 ➔「加入主畫面」。
- **Android (Chrome)**：開啟網址後，點選右上角「⋮」選單 ➔「加到主畫面」➔「安裝」。

---

## 📁 檔案結構

- `index.html`：主頁面與設定／任務彈窗結構
- `styles.css`：響應式樣式與動畫設定
- `app.js`：計時核心、SVG 扇形繪製、拖曳排序、多語系、Web Audio 音效合成與本地儲存
- `manifest.json` / `sw.js` / `icon*.png` / `icon.svg`：PWA 設定與離線快取支援
